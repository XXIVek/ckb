# Инструкция по использованию MCP Knowledge Base для 1С

## Загрузка документации

### Способ 1: По URL
```
load_from_url_tool(url="https://example.com/doc.html")
```
- Автоматически определяет HTML/Markdown
- Определяет категорию по ключевым словам
- Извлекает полезный контент (код, примеры, решения)

### Способ 2: Из папки
```
load_from_folder_tool(folder_path="c:\\docs\\1c")
```
- Поддерживаемые форматы: .html, .md, .docx, .txt, .pdf
- Обрабатывает все файлы рекурсивно
- Фильтрует полезный контент

### Способ 3: Один файл
```
load_and_import("c:\\file.html")
```

## Обратная связь

### Сохранить вопрос-ответ
```
add_snippet_tool(
    question="Как создать справочник в 1С?",
    answer="Для создания справочника нужно...",
    tags="code,howto",
    confidence=0.9
)
```

### Исправить запись
```
fix_snippet_tool(
    snippet_id=42,
    new_answer="Исправленный ответ...",
    reason="Уточнена информация"
)
```

## Анализ контента

### Определить категорию
```
detect_category_tool(text="Синтаксис языка 1С...")
# Вернёт: language
```

### Определить теги
```
detect_tags_tool(text="Пример кода для создания...")
# Вернёт: code, howto
```

## Теги и категории

### Категории
- **language** — Язык БСЛ
- **platform** — Платформа 1С
- **its** — ИТС материалы
- **methodology** — Методология

### Теги
- **code** — примеры кода
- **howto** — инструкции "как сделать"
- **syntax** — описание синтаксиса
- **error** — описания ошибок
- **solution** — варианты решения
- **api** — описание API
- **command** — команды интерфейса

## Поиск

### Поиск по документам
```
search_docs_tool(query="модуль конфигурации", category="language")
```

### Поиск по фрагментам
```
search_fragments_tool(query="ОбъектСправочник", fragment_type="type")
```

### Получить документ
```
get_doc_tool(doc_id=123)
```

## Как AI использует базу

При выполнении задач по 1С:
1. Определяю категорию задачи (language/platform/its/methodology)
2. Ищу релевантные документы/фрагменты
3. Извлекаю полезный контент (код, примеры, решения)
4. При успешном решении предлагаю сохранить ответ
