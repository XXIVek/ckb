# MCP Knowledge Base для 1С:Предприятие

Умная система управления знаниями по платформе 1С:Предприятие с **автоматическим извлечением полезной информации**.

## Что это?

Это MCP-сервер, который позволяет:
1. **Загружать** документацию из любых источников (URL, файлы .html/.md/.docx/.txt/.pdf)
2. **Автоматически определять** категорию по содержимому (language/platform/its/methodology)
3. **Фильтровать полезный контент** (код, примеры, решения ошибок, инструкции)
4. **Сохранять пары вопрос-ответ** для будущего использования (обратная связь)
5. **Искать** нужную информацию быстро и точно

## Новые MCP-инструменты

### Загрузка по URL
```
load_from_url_tool(url: str)
```
Загружает документ по ссылке, автоматически определяет формат и категорию.

### Загрузка из папки
```
load_from_folder_tool(folder_path: str)
```
Загружает все поддерживаемые файлы (.html, .md, .docx, .txt, .pdf) из папки.

### Обратная связь
```
add_snippet_tool(question: str, answer: str, source_url: str = None, tags: str = None, confidence: float = 0.5)
fix_snippet_tool(snippet_id: int, new_question: str = None, new_answer: str = None, reason: str = "Исправление")
```
Добавление и исправление полезных пар вопрос-ответ в базу знаний.

### Анализ контента
```
detect_category_tool(text: str) - определяет категорию по содержимому
detect_tags_tool(text: str) - определяет теги (code, howto, syntax, error, solution, api, command)
```

## Теги классификации
- **code** — примеры кода
- **howto** — инструкции "как сделать"
- **syntax** — описание синтаксиса
- **error** — описания ошибок и их решения
- **solution** — варианты решения проблем
- **api** — описание API платформы
- **command** — описание команд интерфейса

## Категории
- **language** — Язык БСЛ (синтаксис, типы данных, встроенные объекты)
- **platform** — Платформа 1С (COM, HTTP, файловые операции)
- **its** — Материалы с портала ИТС
- **methodology** — Методология (бухгалтерский учёт, НД/НР)

## Использование AI-ассистентом

Когда вам нужно загрузить документацию:
1. Укажите URL или путь к папке
2. AI автоматически определит формат и категорию
3. Полезный контент будет извлечён и промаркирован тегами
4. При успешном решении задачи AI предложит сохранить ответ

## Запуск
```bash
python server.py
```

## Структура
- `src/database.py` — подключение к PostgreSQL
- `src/schema.sql` — схема базы данных
- `src/search.py` — поиск по БД
- `src/importers.py` — импорт из Markdown/HTML
- `src/loader.py` — **умный загрузчик (новое!)**

## Обратная связь
При успешном решении задачи AI может предложить:
- `/add` — сохранить вопрос и ответ в базу знаний
- `/fix` — исправить неточность в существующей записи
