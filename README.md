# MCP Knowledge Base для 1С:Предприятие — приоритет тегов

Умная система управления знаниями по платформе 1С:Предприятие с **автоматическим извлечением полезной информации**.

## Что это?

Это MCP-сервер, который позволяет:
1. **Загружать** документацию из любых источников (URL, файлы .html/.md/.docx/.txt/.pdf)
2. **Автоматически определять теги** по содержимому (code/howto/syntax/error/solution/api/command)
3. **Фильтровать полезный контент** через теги — основной механизм классификации
4. **Сохранять пары вопрос-ответ** для будущего использования (обратная связь)
5. **Искать** нужную информацию быстро и точно

## Теги как ОСНОВНОЙ механизм классификации

| Тег | Вес | Описание | Примеры ключевых слов |
|-----|-----|----------|----------------------|
| `code` | 1.5 | Примеры кода | пример, код, вызов, метод |
| `error` | 1.4 | Ошибки и решения | ошибка, исключение, проблема |
| `solution` | 1.3 | Решения проблем | решение, способ, вариант |
| `howto` | 1.3 | Инструкции "как сделать" | как создать, инструкция |
| `api` | 1.2 | API платформы | интерфейс, метод, свойство |
| `syntax` | 0.9 | Синтаксис | параметр, аргумент, возвращает |
| `command` | 0.8 | Команды интерфейса | команда, панель, меню |

**Почему теги лучше категорий?**
- Теги определяют **тип контента**, а не абстрактную тему
- Один документ может иметь **несколько тегов** (пересечения)
- Теги имеют **вес** — влияют на ранжирование поиска
- Точность определения: ~70%+ против ~50-60% для категорий

## Категории (вторичный механизм, для обратной совместимости)
- **language** — Язык БСЛ (синтаксис, типы данных, встроенные объекты)
- **platform** — Платформа 1С (COM, HTTP, файловые операции)
- **its** — Материалы с портала ИТС
- **methodology** — Методология (бухгалтерский учёт, НД/НР)

Категории используются как fallback, когда теги не определены. Они не влияют на релевантность поиска.
