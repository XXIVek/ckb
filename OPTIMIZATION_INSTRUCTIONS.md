# Инструкция по применению оптимизации MCP-сервера

## Что было сделано

Оптимизированы 3 основных инструмента для уменьшения объёма выводимых данных:

### 1. `search_elements_tool`
- Добавлен параметр `summary_only=True` (по умолчанию)
- **До**: всегда возвращал полный контент элементов
- **После**: по умолчанию возвращает только ID, имя и группу
- Для полного вывода: `summary_only=False`

### 2. `get_element_details_tool`
- Добавлен параметр `full_content=False` (по умолчанию)
- **До**: всегда возвращал полный контент, алиасы и сниппеты (~3000+ символов)
- **После**: по умолчанию возвращает только превью контента (500 символов)
- Для полного вывода: `full_content=True`

### 3. `search_snippets_tool`
- Добавлен параметр `summary_only=True` (по умолчанию)
- **До**: всегда возвращал полные ответы сниппетов
- **После**: по умолчанию возвращает вопрос и превью ответа (1000 символов)
- Для полного вывода: `summary_only=False`

## Как применить изменения

### Шаг 1: Перезапуск MCP-сервера в VS Code

1. Откройте VS Code
2. Нажмите `Ctrl+Shift+P` (или `F1`)
3. Введите команду: **`Cline: Restart MCP Server`**
4. Или через панель команд: `Cline: Configure MCP Servers` → найти сервер `1c-knowledge-base` → перезапустить

### Шаг 2: Проверка работы

После перезапуска проверьте, что изменения работают:

```
get_element_details_tool(element_id=42)
```

**Ожидаемый результат (до оптимизации):** ~3000+ символов полного контента
**Ожидаемый результат (после оптимизации):** ~500 символов превью

### Шаг 3: Использование новых параметров

#### Для получения полной информации:
```
get_element_details_tool(element_id=42, full_content=True)
```

#### Для поиска с полным контентом:
```
search_elements_tool(query="ГенераторСлучайныхЧисел", summary_only=False)
```

#### Для поиска сниппетов с полными ответами:
```
search_snippets_tool(query="ГенераторСлучайныхЧисел", summary_only=False)
```

## Ожидаемый результат

| Инструмент | До оптимизации | После оптимизации (по умолчанию) | После оптимизации (full_content=True) |
