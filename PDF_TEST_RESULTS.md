### 2. Исправление багов в `src/loader.py`

#### Баг #1: Пустой cur.lastrowid при ON CONFLICT UPDATE
**Проблема:** При использовании `INSERT ... ON CONFLICT DO UPDATE` в PostgreSQL, `cur.lastrowid` возвращает 0 вместо ID вставленной/обновлённой записи.

**Решение:** Добавлен явный SELECT после INSERT:
```python
cur.execute("SELECT id FROM docs WHERE local_path = %s", (loc_path,))
doc_id = cur.fetchone()[0]
```

#### Баг #2: Дубликат категории при повторной загрузке
**Проблема:** Цикл for пытался вставить категорию даже если она уже существует.

**Решение:** Добавлена проверка `if code == primary_class` перед INSERT.

### Скорость загрузки:
- Малые файлы (<500 КБ): ~0.5s/файл
- Средние файлы (1-3 МБ): 2-6s/файл
- Большие файлы (>5 МБ): требуют чанкинга

### Используемые модули:
- `src/loader.py` — основной загрузчик
- `src/pdf_loader.py` — загрузка в PostgreSQL
- `src/alias_generator.py` — генерация алиасов
- `PyPDF2` — извлечение текста из PDF
