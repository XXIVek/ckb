# Инструкция по применению системы маркировки источников

## Что было реализовано

Система автоматической маркировки источников для отделения официальной документации от материалов из интернета.

### Новые возможности

#### 1. Автоматическая маркировка при добавлении сниппетов
При указании `source_url` автоматически:
- Добавляются теги: `source:internet`, `source:user`
- Снижается confidence до 0.7 (если было > 0.8)
- Отображается иконка 🌐 в результатах поиска

#### 2. Автоматическая маркировка при создании групп/элементов
При указании `source_url`:
- Для группы: тег `source:internet` + URL в описание
- Для элемента: теги `source:internet`, `source:user`

#### 3. Отображение источников в поиске
- 🌐 — материал из интернета (тег `source:internet`)
- ✅ — официальная документация или проверенный источник
- URL отображается в полном выводе

## Как использовать

### 1. Добавление сниппета с указанием источника:
```python
add_snippet_tool(
    question="Как создать ГенераторСлучайныхЧисел?",
    answer="ГСЧ = Новый ГенераторСлучайныхЧисел();",
    source_url="https://helpf.pro/faq8/view/297.html",
    tags="code,api"
)
# → Автоматически: теги ['source:internet', 'source:user'], confidence=0.7
```

### 2. Добавление сниппета без источника (официальная документация):
```python
add_snippet_tool(
    question="Как создать ГенераторСлучайныхЧисел?",
    answer="ГСЧ = Новый ГенераторСлучайныхЧисел();",
    tags="code,api"
)
# → Без маркировки источника, confidence=0.9 (по умолчанию)
```

### 3. Создание группы с указанием источника:
```python
create_group_tool(
    name="Генератор случайных чисел",
    description="Использование ГенераторСлучайныхЧисел и функции Рандом в 1С.",
    tags="language,random",
    source_url="https://helpf.pro/faq8/view/297.html"
)
# → Автоматически: тег 'source:internet', URL в описании
```

### 4. Создание элемента с указанием источника:
```python
create_element_tool(
    group_id=12,
    name="ГенераторСлучайныхЧисел",
    content="Описание объекта...",
    tags="language,api",
    source_url="https://helpf.pro/faq8/view/297.html"
)
# → Автоматически: теги ['source:internet', 'source:user']
```

## Преимущества

1. **Прозрачность** — пользователь сразу видит, откуда взялась информация
2. **Доверие** — можно оценить надёжность источника по иконке и confidence
3. **Автоматизация** — маркировка происходит автоматически при загрузке
4. **Фильтрация** — можно отфильтровать материалы по тегу `source:internet`

## Теги в базе данных

| Тег | Weight | Назначение |
|-----|--------|-----------|
| `code` | 1.5 | Примеры кода |
| `error` | 1.4 | Ошибки |
| `solution` | 1.3 | Решения |
| `howto` | 1.3 | Инструкции |
| `api` | 1.2 | API платформы |
| `source:official` | 1.0 | Официальная документация |
| `syntax` | 0.9 | Синтаксис |
| `source:its` | 0.9 | Материалы с ИТС |
| `command` | 0.8 | Команды |
| `source:internet` | 0.7 | Материалы из интернета |
| `source:user` | 0.6 | Пользовательский код |

## Обновление существующих данных

При запуске `add_source_tags.py`:
- Добавлены новые теги в базу данных
- Все сниппеты с `source_url` автоматически помечены тегом `source:internet`

Будущие загрузки из интернета будут автоматически маркироваться системой.
