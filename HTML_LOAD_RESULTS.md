## Качество извлечения HTML

### Что работает отлично:
1. **Извлечение текста** — полный текст извлекается корректно
2. **Определение тегов** — автоматическая классификация по типам контента
3. **Генерация алиасов** — 598 алиасов для поиска
4. **Структура заголовков** — HTML-теги h1-h6 распознаются

### Ограничения:
1. **Фрагменты (doc_fragments)** — не извлекаются автоматически
   - Методы, классы, типы данных не детектируются
   - Требуется доработка HTML-экстрактора
   
2. **Сниппеты кода** — не извлекаются
   - Блоки `<pre><code>` не парсятся отдельно
   - Код включён в общий контент документа

3. **Чистка HTML** — много пустых строк и пробелов
   - Требуется дополнительная обработка текста
