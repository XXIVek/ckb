
# RULES: Поиск информации в 1C Knowledge Base

## КОНТЕКСТ И АРХИТЕКТУРА (актуально на 07.10.2026)

База данных local_doc содержит документацию по платформе 1С:Предприятие v2 (BSL).

### Основные таблицы

| Таблица | Назначение | Примерное количество |
|---------|-----------|---------------------|
| groups | Группы документации (каждый HTML = группа) | ~25 495 |
| knowledge_snippets | Сниппеты кода (вопрос-ответ с примером) | ~1 496 |
| alias_targets | Связи алиасов с группами/сниппетами | ~198 632 |
| doc_categories | Категории документации | 4 |

### Поля groups (BSL-документация)

| Поле | Описание |
|------|----------|
| **pagetitle** | Официальное название из `<h1 class="V8SH_pagetitle">` — участвует в full-text поиске |
| **title** | Из `<p class="V8SH_title">` — используется для генерации алиасов (вес 1.0/1.2) |
| **heading** | Из `<p class="V8SH_heading">` — заполнено у 22 671 из 25 495 групп, вес алиасов 0.7/0.9 |
| **versionInfo** | Из `<p class="V8SH_versionInfo">` — проверка совместимости платформы |
| description | ВЕСЬ `<body>` HTML (для долговременной памяти AI) |

## АЛГОРИТМ ПРИНЯТИЯ РЕШЕНИЙ ПРИ ПОИСКЕ

### Шаг 1: Определение типа запроса

| Тип запроса | Пример | Что искать первым |
|-------------|--------|-------------------|
| Конкретный метод/функция | Как создать Справочник, Метод Random() | `search_docs_tool("Справочник")` |
| Пример кода/решение | Обработка исключений, HTTP-запрос | `search_docs_tool("обработка исключений")` |
| Общая информация | Что такое регистр | `search_docs_tool("регистр")` |

### Шаг 2: Приоритет поиска (внутри search_docs_tool)

1. **Поиск по алиасам** (rank 2.0): Точное совпадение `alias_name` → возвращает **и группы, и сниппеты** (deduplicated по ID)
2. **Full-text поиск по groups** (rank 1.0): Ищет по `name || pagetitle`. **heading НЕ участвует!**
3. **Full-text поиск по snippets** (rank 0.5): Ищет по `question || answer`
4. **Результаты сортируются по rank DESC**, limit применяется в конце.

### Шаг 3: Интерпретация результатов

Если найдены группы:

1. Проверяем tags — категория документа (language, platform, bsl, objects, tables)
2. Смотрим pagetitle — официальное название из документации
3. Анализируем description — полный HTML-контент страницы
4. Проверяем versionInfo — с какой версии доступно

Если найдены сниппеты:

1. Смотрим confidence — уверенность извлечения кода (0.5-1.0)
2. Анализируем question — контекст использования
3. Извлекаем answer — пример кода

ПРАВИЛА ИНТЕРПРЕТАЦИИ РЕЗУЛЬТАТОВ
1. Ранжирование результатов
Фактор	Вес	Описание
rank (из поиска)	высокий	Результат full-text поиска по relevance
pagetitle совпадение	высокий	Точное совпадение = лучший результат
confidence сниппета	средний	confidence > 0.8 = качественный код
tags: bsl	высокий	Документация BSL — приоритетный источник
2. Обработка пустых результатов
Если search_docs_tool вернул "Результатов не найдено":

Попробовать синоним (например, "ubound" вместо "убound")
Упростить запрос (убрать технические термины)
Использовать category filter (category="language,bsl")
3. Работа с HTML-контентом
description содержит ВЕСЬ body HTML:

Может включать ссылки, таблицы, стили
Для AI: полезен для понимания контекста
Для пользователя: извлекать только текст (убрать теги)
4. versionInfo
Если group[versionInfo] не пустой:

Использовать для проверки совместимости
"Доступен, начиная с версии 8.0" = минимальная версия платформы

⚠️ ЧАСТЫЕ ОШИБКИ И КАК ИЗБЕЖАТЬ
Ошибка: Использование таблиц search_aliases / docs / doc_fragments
Эти таблицы НЕ СУЩЕСТВУЮТ! Использовать alias_targets и groups.

Ошибка: Поиск только по name
search_docs_tool ищет по: name || pagetitle (groups) + question || answer (snippets) heading НЕ участвует в full-text поиске — только для генерации алиасов.

Ошибка: Игнорирование category
Если знаете категорию — всегда указывайте:

search_docs_tool(query="HTTP", category="platform") — быстрее и точнее
search_docs_tool(query="Random", category="language,bsl") — BSL-функции
Ошибка: Не проверка versionInfo
Всегда проверяйте versionInfo для совместимости!

Ошибка: Использование русских символов для алиасов
Алиасы генерируются из ASCII (pagetitle/heading). Используйте "ubound", а не "убound".
