# Система маркировки источников в 1C Knowledge Base

## Проблема

При загрузке документации из интернета (HTML, markdown, URL) невозможно отличить:
- Официальную документацию 1С
- Материалы с портала ИТС
- Пользовательский код из интернета

Это приводит к тому, что пользователь не знает, можно ли доверять полученной информации.

## Решение

Введена система автоматической маркировки источников при загрузке материалов.

### Новые теги

| Тег | Назначение | Weight | Описание |
|-----|-----------|--------|----------|
| `source:internet` | Материалы из интернета | 0.7 | Пользовательский код или материалы, загруженные из внешних источников (HTML, markdown) |
| `source:official` | Официальная документация | 1.0 | Проверенные материалы из официальной документации 1С |
| `source:its` | Материалы с ИТС | 0.9 | Документация и материалы с портала ИТС |
| `source:user` | Пользовательский код | 0.6 | Код, предоставленный пользователями или найденный в интернете |

### Автоматическая маркировка

#### 1. При загрузке из URL (`load_from_url_tool`)
- Автоматически добавляется тег `source:internet`
- URL сохраняется в `source_url`
- Confidence снижается до 0.7 (для пользовательского кода)

#### 2. При создании сниппета с `source_url` (`add_snippet_tool`)
- Автоматически добавляются теги: `source:internet`, `source:user`
- URL отображается в выводе
- Confidence снижается до 0.7 (если было > 0.8)

#### 3. При создании группы/элемента с `source_url`
- Для группы: автоматически добавляется тег `source:internet` и URL в описание
- Для элемента: автоматически добавляются теги `source:internet`, `source:user`

### Отображение источников

#### В поиске сниппетов
```
[ID:7] 🌐 Как создать ГенераторСлучайныхЧисел... → НачальноеЧисло = 167; ГСЧ = Новый... confidence=0.9
[ID:8] ✅ Как создать ГенераторСлучайныхЧисел с автоматической... → ГСЧ = Новый ГенераторСлучайныхЧисел(); СлучайноеЧисло = ГСЧ.... confidence=0.9
```

- 🌐 — материал из интернета (тег `source:internet`)
- ✅ — официальная документация или проверенный источник

#### В полном выводе сниппетов
```
[ID:7] 🌐 Как создать ГенераторСлучайныхЧисел... → НачальноеЧисло = 167; ГСЧ = Новый... confidence=0.9
[URL: https://helpf.pro/faq8/view/297.html]
```

### Примеры использования

#### Добавление сниппета с указанием источника:
```python
add_snippet_tool(
    question="Как создать ГенераторСлучайныхЧисел?",
    answer="ГСЧ = Новый ГенераторСлучайныхЧисел();",
    source_url="https://example.com/article",
    tags="code,api",
    confidence=0.9
)
# → Автоматически: теги ['source:internet', 'source:user'], confidence=0.7
```

#### Добавление сниппета без источника:
```python
add_snippet_tool(
    question="Как создать ГенераторСлучайныхЧисел?",
    answer="ГСЧ = Новый ГенераторСлучайныхЧисел();",
    tags="code,api"
)
# → Без маркировки источника, confidence=0.9 (по умолчанию)
```

#### Создание группы с указанием источника:
```python
create_group_tool(
    name="Генератор случайных чисел",
    description="Использование ГенераторСлучайныхЧисел и функции Рандом в 1С.",
    tags="language,random",
    source_url="https://helpf.pro/faq8/view/297.html"
)
# → Автоматически: тег 'source:internet', URL в описании
```

### Обновление существующих данных

При запуске `add_source_tags.py`:
- Добавлены новые теги в базу данных
- Все сниппеты с `source_url` автоматически помечены тегом `source:internet`

## Преимущества

1. **Прозрачность** — пользователь сразу видит, откуда взялась информация
2. **Доверие** — можно оценить надёжность источника по иконке и confidence
3. **Автоматизация** — маркировка происходит автоматически при загрузке
4. **Гибкость** — можно отфильтровать материалы по тегу `source:internet`

## Файлы системы

- `src/mcp_tools.py` — логика автоматической маркировки
- `server.py` — обёртки инструментов с поддержкой `source_url`
- `add_source_tags.py` — скрипт для добавления тегов и обновления данных
- `check_tags.py` — проверка текущих тегов в базе
