# Оптимизация MCP-сервера 1C Knowledge Base

## Проблема
MCP-инструменты возвращали полные объёмы данных (контент элементов, сниппеты, алиасы) при каждом вызове, что приводило к "захламлению" вывода в Cline.

## Решение
Добавлены параметры для управления объёмом выводимых данных:

### 1. `search_elements_tool(query, limit=20, summary_only=True)`
- **summary_only=True** (по умолчанию): возвращает только ID, имя и группу элемента
- **summary_only=False**: включает полный контент элемента

### 2. `get_element_details_tool(element_id, full_content=False)`
- **full_content=False** (по умолчанию): возвращает только превью контента (500 символов)
- **full_content=True**: включает полный контент, алиасы и сниппеты

### 3. `search_snippets_tool(query, limit=20, summary_only=True)`
- **summary_only=True** (по умолчанию): возвращает вопрос и превью ответа (1000 символов)
- **summary_only=False**: включает полный ответ

## Изменённые файлы
- `src/mcp_tools.py` — добавлены параметры `summary_only` и `full_content`
- `server.py` — обновлены обёртки инструментов с новыми параметрами

## Примеры использования

### Поиск элементов (краткий):
```
search_elements_tool(query="ГенераторСлучайныхЧисел")
→ Найдено 4 элементов:
[ID:8] Процедуры и функции работы... (группа: ...)
[ID:38] ГенераторСлучайныхЧисел (группа: ...)
...
```

### Поиск элементов (полный):
```
search_elements_tool(query="ГенераторСлучайныхЧисел", summary_only=False)
→ Найдено 4 элементов:
[ID:8] Процедуры и функции работы... — Начальное число = ...
[ID:38] ГенераторСлучайныхЧисел (группа: ...) — Генератор случайн...
...
```

### Детали элемента (краткие):
```
get_element_details_tool(element_id=38)
→ [ID:38] ГенераторСлучайныхЧисел (группа: Генератор случайных чисел)
Содержимое: Генератор случайных чисел инициализируется начальным числом...
```

### Детали элемента (полные):
```
get_element_details_tool(element_id=38, full_content=True)
→ [ID:38] ГенераторСлучайныхЧисел (группа: Генератор случайных чисел)
Содержимое: Полный текст...

Алиасы (1):
  - генераторслучайныхчисел (weight=1.0)

Сниппеты (2):
  [ID:7] Как создать ГенераторСлучайныхЧисел с фиксированным начальным числом?... confidence=0.9
  [ID:8] Как создать ГенераторСлучайныхЧисел с автоматической инициализацией?... confidence=0.9
```

### Поиск сниппетов (краткий):
```
search_snippets_tool(query="ГенераторСлучайныхЧисел")
→ Найдено 5 сниппетов:
[ID:7] Как создать ГенераторСлучайныхЧисел с фиксированным... → НачальноеЧисло = 167; ГСЧ = Новый... confidence=0.9
...
```

### Поиск сниппетов (полный):
```
search_snippets_tool(query="ГенераторСлучайныхЧисел", summary_only=False)
→ Найдено 5 сниппетов:
[ID:7] Как создать ГенераторСлучайныхЧисел с фиксированным... → Полный ответ со сниппетом кода... confidence=0.9
...
```

## Результат
- **До оптимизации**: `get_element_details_tool(element_id=42)` возвращал ~3000+ символов
- **После оптимизации**: `get_element_details_tool(element_id=42)` возвращает ~500 символов (превью)
- **Экономия**: в 6 раз меньше данных при стандартном использовании

## Важно
Изменения применяются после перезапуска MCP-сервера. Если вы используете Cline в VS Code, перезапустите сервер через панель команд: `Cline: Restart MCP Server`.
